Formal Verification Theory & FAQ

How AEGIS Eliminates Hallucinations with Microsoft Z3

Standard AI coding assistants generate security patches with zero mathematical guarantees, frequently hallucinating incorrect syntax or introducing subtle secondary vulnerabilities. AEGIS pairs LLM program synthesis with an SMT formal solver to guarantee correctness.

Why is Z3 SMT superior to unit tests alone?

Unit tests only evaluate discrete inputs chosen by the developer. Microsoft Z3 evaluates the First-Order Logic formula over the entire infinite set of all possible string inputs ($\forall x \in \text{Strings}$). If a single attack vector can escape, Z3 generates a concrete counterexample.

What attack classes does AEGIS cover?

AEGIS covers injection vectors (SQLi, NoSQLi, SSTI, ReDoS, LPDoS), client-side vulnerabilities (DOM XSS), network boundary escapes (SSRF), and broken object level authorization (BOLA/IDOR).

How does the SQLite Data Provenance work?

Every card and badge in the dashboard is bound directly to persistent records in data/aegis.db. There is zero mock confusion; queries execute live in SQLite WAL mode with microsecond latency.

Can AEGIS be run in GitHub Actions / GitLab CI?

Yes. The AEGIS engine runs as a lightweight CLI (npm test or npm run analyze) returning non-zero exit codes when invariants fail and automatically generating cryptographically signed GitHub Pull Requests upon proof success.
